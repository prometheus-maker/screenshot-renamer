How does it work?

Your browser reads the text in each image with Tesseract.js (open-source OCR). The line with the largest letters, usually a title or heading, becomes the file name. You can edit any name before downloading. The first run downloads the text-reading model (about 10 MB); after that it is cached.

Your images never leave your computer: there is no server, and the page has no analytics or cookies.

Dates like 2024-03-05 or 2024-03-05 at 14.22.10 in the old name are kept in front, so your files still sort by time. Untick the box to drop them.
